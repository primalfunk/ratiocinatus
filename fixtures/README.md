# Fixture provenance and license

All fixtures here were authored as plain synthetic test material for
Ratiocinatus on 2026-07-26. They contain no third-party media and are offered
for use with this repository under the eventual project license. The `.wav`
fixture is deliberately symbolic bytes, not valid media; Phase 0 treats sources
as opaque. `opaque-copy.txt` is byte-identical to `opaque.txt`;
`opaque-modified.txt` is intentionally different; `providers/malformed.json`
is a controlled invalid provider response. An unreadable-fixture condition is
created during tests using a missing path because portable permission semantics
differ by operating system.
